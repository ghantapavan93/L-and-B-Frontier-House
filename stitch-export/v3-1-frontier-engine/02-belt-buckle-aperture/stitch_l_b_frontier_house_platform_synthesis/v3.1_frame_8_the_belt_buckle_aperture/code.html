Production Specifications

Three.js Geometry Layers

  • Base mesh: High-poly chamfered rectangle (seg: 64x64).
  • Material: MeshPhysicalMaterial, roughness 0.2, metalness 0.9.
  • Displacement map applied for 'tooled leather' base surround.
  • Z-index layering critical for portal masking effect.

GLSL Edge Lighting

  • Custom shader material for inner aperture rim.
  • Fresnel effect driven by camera angle vector.
  • Color pulse uniform mapped to scroll velocity (Indigo -> Bone).
  • Volumetric light ray scattering on z-axis push.
